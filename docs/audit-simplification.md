# Audit visuel avant simplification

Audit du 29 octobre 2026, avant modification des écrans. 23 vues/états × 390, 768 et 1440 px : 69 captures dans `test-results/ux-before/`. Aucun débordement ou défaut de contraste détecté par les mesures initiales ; les problèmes portent sur la densité, la hiérarchie et les répétitions.

| Écran / état | Constat | Correction retenue |
| --- | --- | --- |
| Accueil public | Onze sections, slogans, listes et CTA répétés, promesses futures très présentes | Conserver les informations et liens, raccourcir les titres et explications, regrouper les contenus secondaires et alléger la présentation |
| Connexion / inscription | La refonte précédente fournit déjà une hiérarchie claire | Conserver la carte et le bilinguisme ; retirer seulement les répétitions résiduelles |
| Vérification e-mail | Adresse, action et échéance dispersées dans plusieurs paragraphes | Regrouper le message utile et garder les informations de sécurité |
| Récupération / réinitialisation | Structure satisfaisante, indications de mot de passe à conserver | Ajuster les libellés sans changer les contrôles |
| Invitation | Nom d’espace répété, explication du partage redondante | Destinataire, organisation, expiration et action principale |
| Création d’espace | Bienvenue personnalisée, introduction et aide répétées | Titre d’action, champ entreprise et bouton principal |
| Dashboard | Sept entrées de navigation différentes des autres pages ; graphiques avant les échéances ; activité récente absente | Navigation uniforme ; trois listes de relances en premier ; activité visible ; statistiques secondaires repliables |
| Contacts / entreprises | Même grand titre et slogan dans les deux vues ; double recherche et pied de page répétitif ; actions surdimensionnées | Titre spécifique, recherche de répertoire dominante, actions secondaires regroupées et lignes compactes |
| Fiche contact | Bandeau « démonstration » incorrect ; actions de suppression très visibles ; encadrés et pagination vide | En-tête utile ; actions regroupées ; coordonnées et notes plus sobres ; pagination utile uniquement |
| Fiche entreprise | Historique avant contexte et notes ; gestion éparpillée dans les cartes | Notes puis historique ; gestion dans l’en-tête ; coordonnées et prochaines relances compactes |
| Notes / historique | Cartes répétées, grands espaces et commandes de pagination même avec une seule page | Séparateurs simples, formulaire court, pagination conditionnelle |
| Relances | Colonne promotionnelle, trois cartes dont deux vides, date et responsable affichés deux fois | Liste métier pleine largeur ; échéance unique ; accès direct aux actions existantes Terminer / Reporter |
| Formulaires contact / entreprise | Tous les champs ouverts, formulaire long, champs obligatoires non marqués | Champs courants en premier, informations facultatives regroupées, repère obligatoire et erreurs liées au formulaire |
| Formulaire relance | Sélection contact / entreprise et textes techniques très présents | Objet, échéance et responsable lisibles, rattachement conservé |
| Collaborateurs / invitations | Formulaire d’invitation toujours ouvert, textes de partage répétés | Liste des membres d’abord ; invitation dans une section identifiable, échéance du lien conservée |
| Accès / paramètres | Champ de transfert visible même sans désactivation | Affichage conditionnel du transfert et consignes de protection conservées |
| Changement d’organisation | Paragraphe explicatif évident | Sélecteur et action |
| Vide / erreur / confirmation | Slogans et avertissements génériques, répétition titre / texte / bouton | Un message factuel, action de reprise, conséquences irréversibles explicites |

Le remplacement du hero demandé ensuite sera effectué avec le fichier exact fourni par l’utilisateur dès qu’un chemin ou une URL accessible sera disponible ; aucune image de remplacement ne sera inventée.
